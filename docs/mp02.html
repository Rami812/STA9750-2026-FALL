Intro:

Our results are based on analyzing different agency’s emission rates across fuel types, modes of transportation while accounting for their respective sizes across all the States in the US. MP02: Intro: In this project, we take the role of an ExecExecutive Director of the Green Transit Alliance (GTA) and publish annual awards in relation to the “greenest” public transit agencies. Our main criteria of estimating effective emissions reductions by agency is based on a combination of: - Local ridership data - Emissions estimates of public transit vehicles We compare emission records to those that which would have happened if all riders would have driven to their destination. We will be utilizing the following datasets for this project: - State Electricity Profiles - Energy Consumption - Transit Service Provided

The private-car comparison figures used at the end of this report come from the EPA’s Greenhouse Gas Emissions from a Typical Passenger Vehicle (which indciates that ~400 g/0.882 lb CO2 per vehicle-mile) and the FHWA’s Average Vehicle Occupancy Factors(which indicates that ~1.7 people per car, derived from the 2017 National Household Travel Survey). If we divide the two figures we get an emissions-per-passenger-mile baseline that can be used to compare to the transit figures for the winner of each category.

get_eia_sep <- function(state, abbr){
    library(tidyverse)
    library(stringr)
    library(httr2)
    library(rvest)
    library(fs)
  
    state_formatted <- str_to_lower(state) |> str_replace_all("\\s", "")
    
    dir_name <- fs::path("data", "mp02")
    file_name <- fs::path(dir_name, state_formatted)
    
    fs::dir_create(dir_name, recurse=TRUE)

    # A cached file is only valid if it actually contains a table -- EIA's
    # edge server occasionally blocks a request and returns a small "Access
    # Denied" page instead, which would otherwise be cached forever.
    has_table <- function(path){
        fs::file_exists(path) && !is.na(read_html(path) |> html_element("table") |> xml2::xml_name())
    }

    if(!has_table(file_name)){
        BASE_URL <- "https://www.eia.gov"
        RESPONSE <- request(BASE_URL) |>
          req_url_path("electricity",
                       "state",
                       state_formatted) |>
          req_headers(
            `User-Agent` = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:149.0) Gecko/20100101 Firefox/149.0"
            ) |>
          req_retry(
                max_tries = 4,
          ) |>
          req_perform(file_name)

        resp_check_status(RESPONSE)
    }

    TABLE <- read_html(file_name) |>
        html_element("table") |>
        html_table() |>
        mutate(Item = str_to_lower(Item))
    
    if("U.S. rank" %in% colnames(TABLE)){
        TABLE <- TABLE |> rename(Rank = `U.S. rank`)
    }
    
    CO2_MWh <- TABLE |> 
        filter(Item == "carbon dioxide (lbs/mwh)") |>
        pull(Value) |> 
        str_replace_all(",", "") |>
        as.numeric()
    
    PRIMARY <- TABLE |> 
        filter(Item == "primary energy source") |> 
        pull(Rank)
    
    RATE <- TABLE |>
        filter(Item == "average retail price (cents/kwh)") |>
        pull(Value) |>
        as.numeric()
    
    GENERATION_MWh <- TABLE |>
        filter(Item == "net generation (megawatthours)") |>
        pull(Value) |>
        str_replace_all(",", "") |>
        as.numeric()
    
    data.frame(CO2_MWh               = CO2_MWh, 
               primary_source        = PRIMARY,
               electricity_price_MWh = RATE * 10, # / 100 cents to dollars &
               # * 1000 kWh to MWH 
               generation_MWh        = GENERATION_MWh, 
               state                 = state, 
               abbreviation          = abbr
    )
}

load_ntd_energy <- function(){
  library(readxl)
  library(httr2)
  library(tidyverse)
  library(fs)
  
  # Create 'data/mp02' directory if not already present
  DATA_DIR <- fs::path("data", "mp02")
  fs::dir_create(DATA_DIR, recurse=TRUE)

  NTD_ENERGY_FILE <- fs::path(DATA_DIR, "2025_ntd_energy.xlsx")

  if(!fs::file_exists(NTD_ENERGY_FILE)){
    library(httr2)
  
    request("https://www.transit.dot.gov/") |>
      req_url_path("sites",
                   "fta.dot.gov",
                   "files",
                   "2026-09",
                   "2025 Energy Consumption_260806.xlsx") |> 
      req_headers(
        `User-Agent` = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:149.0) Gecko/20100101 Firefox/149.0") |> 
      req_perform(NTD_ENERGY_FILE)
  }
  
  if(file.info(NTD_ENERGY_FILE)$size < 1e4){
        cat("I was unable to download the NTD Energy File. Please try again.\n")
        stop("Download failed. Please delete the corrupted file by running `unlink('data/mp02/2025_ntd_energy.xlsx')` and try again.")
    }

  to_numeric_fill_0 <- function(x){
    x <- if_else(x == "-", NA, x)
    replace_na(as.numeric(x), 0)
  }

  read_excel(NTD_ENERGY_FILE) |> 
    select(-c(`Reporter Type`, 
              `Reporting Module`, 
              `Gallons of Other Fuel`, 
              `Other Fuel Description`)) |>
    mutate(across(-c(`Agency Name`, 
                     `Mode`,
                     `TOS`), 
                  to_numeric_fill_0)) |>
    group_by(`NTD ID`, `Mode`, `Agency Name`) |>
    summarize(across(where(is.numeric), sum), 
              .groups = "keep") |>
    mutate(ENERGY = sum(c_across(c(where(is.numeric))))) |>
    filter(ENERGY > 0) |>
    select(-ENERGY) |>
    ungroup()
}

load_ntd_service <- function(){
  library(httr2)
  library(tidyverse)
  library(fs)
  
  # Create 'data/mp02' directory if not already present
  DATA_DIR <- fs::path("data", "mp02")
  fs::dir_create(DATA_DIR, recurse=TRUE)

  NTD_SERVICE_FILE <- fs::path(DATA_DIR, "2025_ntd_service.csv")

  if(!fs::file_exists(NTD_SERVICE_FILE)){
    library(httr2)
  
    request("https://data.transportation.gov/resource/4fir-qbim.csv") |>
      req_url_query(`$query`=paste(
        "SELECT  `_5_digit_ntd_id` AS `NTD_ID`", 
        "`max_agency` AS `AGENCY`",
        "`max_reporter_type` AS `reporter_type`",
        "`max_organization_type` AS `organization_type`",
        "`max_city` AS `city`",
        "`max_state` AS `state`",
        "`mode`",
        "`type_of_service`",
        "`max_primary_uza_code` as `uza_code`",
        "`max_primary_uza_name` as `uza_name`",
        "`max_primary_uza_area_sq_miles` as `uza_sq_miles`",
        "`max_primary_uza_population` as `uza_population`",
        "`max_service_area_sq_miles` as `service_area_sq_miles`",
        "`max_service_area_population` as `service_area_population`",
        "`questionable_record` as `flagged_likely_inaccurate`",
        "`sum_unlinked_passenger_trips_upt` as `total_upt`",
        "`sum_passenger_miles` WHERE caseless_one_of(`report_year`, '2025') limit 50000", 
        sep=",")) |>
      req_headers(
        `User-Agent` = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:149.0) Gecko/20100101 Firefox/149.0") |> 
      req_perform(NTD_SERVICE_FILE)
  }
  
  if(file.info(NTD_SERVICE_FILE)$size < 1e4){
        cat("I was unable to download the NTD Service File. Please try again.\n")
        stop("Download failed. Please delete the corrupted file by running `unlink('data/mp02/2025_ntd_service.xlsx')` and try again.")
    }

  read_csv(NTD_SERVICE_FILE) |>
    mutate(flagged_likely_inaccurate = !is.na(flagged_likely_inaccurate))
}

Calculating Total Emissions

To estimate emissions, we join all three tables into a single table with one row per Agency + Mode pair, carrying the state (from NTD_SERVICE), every fuel source (from NTD_ENERGY), and the state’s grid CO2 intensity (from EIA_SEP_REPORT).

Joining NTD_SERVICE, NTD_ENERGY, and EIA_SEP_REPORT

NTD_SERVICE reports multiple rows per Agency + Mode (this gets further split by type_of_service, i.e. directly-operated vs. purchased transportation), so we first collapse these down to one row per ntd_id + modeby summing ridership and rec-oding mode with the same recode_values() mapping that we had used for NTD_ENERGY before.

R-code 
NTD_SERVICE_AGG <- NTD_SERVICE |>
    mutate(mode = recode_values(mode,
        "AR" ~ "Alaska Railroad",
        "CB" ~ "Commuter Bus",
        "CC" ~ "Cable Car",
        "CR" ~ "Commuter Rail",
        "DR" ~ "Demand Response",
        "FB" ~ "Ferryboat",

        "YR" ~ "Hybrid Rail",
        default = "Unknown"

We then perform an inner_join() between this transformed table with NTD_ENERGY based on the column values of ntd_id and mode (this allows us to keep Agency + Mode pairs that actually report both ridership and fuel use). Subsequently, we perform a left_join() to utilize the result along with EIA_SEP_REPORT’s co2_mwh. We perform this by matching NTD_SERVICE’s state abbreviation to EIA_SEP_REPORT’s abbreviation column:

R-code

# right here, rather than relying on the earlier type-fix chunk having
# already run -- this keeps the join correct even if `NTD_ENERGY` or
# `NTD_SERVICE` get reloaded/re-run out of order.
EMISSIONS <- NTD_SERVICE_AGG |>
    mutate(ntd_id = as.character(ntd_id)) |>
    inner_join(
        NTD_ENERGY |>
            mutate(
                ntd_id = str_pad(as.character(ntd_id), width = 5, pad = "0"),
                # `default = mode` makes this a safe no-op if NTD_ENERGY's
                # mode was already recoded to full names above -- it only
                # recodes values that are still raw 2-letter codes, so this
                # join can't silently return 0 rows if that chunk gets
                # re-run out of order.
                mode = recode_values(mode,
                    "AR" ~ "Alaska Railroad",
                    "CB" ~ "Commuter Bus",
                    "CC" ~ "Cable Car",
                    "CR" ~ "Commuter Rail",
                    "DR" ~ "Demand Response",
                    "FB" ~ "Ferryboat",
                    "HR" ~ "Heavy Rail",
                    "IP" ~ "Inclined Plane",
                    "LR" ~ "Light Rail",
                    "MB" ~ "Bus",

                    "RB" ~ "Bus Rapid Transit",
                    "SR" ~ "Streetcar Rail",
                    "TB" ~ "Trolleybus",
                    "TR" ~ "Aerial Tramway",
                    "VP" ~ "Vanpool",
                    "YR" ~ "Hybrid Rail",
                    default = mode

Computing Total Emissions

The EIA publishes CO2 emission factors by fuel (eia.gov/environment/emissions/co2_vol_mass.php), but it does not cover every fuel NTD reports (e.g. biodiesel, ethanol, CNG, and LNG are missing). For the missing ones, we can hard-code the standard factors from the EPA’s GHG Emission Factors Hub and convert to the same lb CO2/gallon units. Electric modes use each agency’s own state grid intensity (co2_mwh) rather than a fixed factor. Hydrogen fuel cells are treated as zero direct (tailpipe) CO2, since combustion only produces water (we are ignoring upstream production as well as assuming that the electric terms only capture generation-side CO2 and not transmission losses or vehicle manufacturing):

R-code 
# lb CO2 per gallon -- EIA where available, EPA GHG Emission Factors Hub
# otherwise (biodiesel, ethanol, CNG as gasoline-gallon-equivalent, LNG)
GAL_GASOLINE  <- 18.73   # EIA
GAL_DIESEL    <- 22.45   # EIA
GAL_KEROSENE  <- 21.78   # EIA
GAL_LPG       <- 12.68   # EIA (propane)
GAL_BUNKER    <- 24.78   # EIA (residual fuel oil, closest match to bunker fuel)
GAL_BIODIESEL <- 20.84   # EPA
GAL_ETHANOL   <- 12.68   # EPA
GAL_CNG       <- 15.21   # EPA, NTD gallons assumed to be gasoline-gallon-equivalent
GAL_LNG       <-  9.83   # EPA

EMISSIONS <- EMISSIONS |>
    mutate(total_emissions_lbs =
        biodiesel_gal   * GAL_BIODIESEL +
        bunker_fuel_gal * GAL_BUNKER +
        cng_gal         * GAL_CNG +
        diesel_gal      * GAL_DIESEL +
        ethanol_gal     * GAL_ETHANOL +
        gasoline_gal    * GAL_GASOLINE +
        kerosene_gal    * GAL_KEROSENE +
        lng_gal         * GAL_LNG +
        lpg_gal         * GAL_LPG +
        hydrogen_kg     * 0 +
        (electric_battery_kwh + electric_propulsion_kwh) / 1000 * co2_mwh
    )

Normalizing Emissions to Transit Usage

We know that a large agency will almost always have higher total emissions than a small one due to serving far more riders, so raw totals are not a fair way to compare “green-ness” across agencies. Instead, we normalize emissions by ridership, computing emissions per UPT and per passenger mile for a fairer comparison

Aggregating to the Agency Level

As ridership is reported at the Agency level, not at the Agency + Mode level, we first sum emissions and ridership across all of an agency’s different modes. Agencies based in DC or Puerto Rico have no known electricity CO2 factor, so we do not use na.rm = TRUE to retain their information. We ensure that an agency with even one mode of unknown emissions keeps an overall total of NA rather than being discretely undercounted:

R-code 
AGENCY_EMISSIONS <- EMISSIONS |>
    group_by(agency, state) |>
    summarize(
        total_emissions_lbs = sum(total_emissions_lbs),
        total_upt            = sum(total_upt),
        passenger_miles      = sum(passenger_miles),
        .groups = "drop"
    )

Determining the Metrics for Award Winners

Based on the normalized emissions figures from the previous section, we can design metrics for the following two GTA IV Green Transit Awards:

  • Greenest Transit Agency: The agency that has the lowest emissions per passenger mile among all agencies (we excluded agencies that have total unlinked passenger trips that are less than 10,000 miles as they would by default seem more green due to their lower size)
  • Least Green Transit Agency: Out of all the large agencies, the one that has the highest emissions per passenger mile is determined as the criteria for this award. We focus on large agencies in particular to ensure a high-impact system is being looked at instead of a small one that is used by a lower population.

Award: Greenest Transit Agency

We are excited to announce the results of the 2026 Green Transit Alliance (GTA) awards.Our results are based on analyzing different agency’s emission rates across fuel types, modes of transportation while accounting for their respective sizes across all the States in the US. To underscore of how much important Transit Systems are in tackling carbon emissions we have included comaparison across the median as well as the typical carbon emission for a private car.

We estimated each Agency’s and medium of transportation’s total CO2 emissions from its fuel and electricity use as an unique pair. Subsequently, we summed up by the agency level, and divide by total passenger miles traveled. In a similar fashion, the lb CO2 per passenger mile was measured used throughout this report. Seattle Center Monorail (WA) wins with just 0.064 lb CO2 per passenger mile, powered by Washington’s hydroelectric-heavy, exceptionally green grid.

The typical US transit agency emits 1.09 lb per passenger mile (over 17 time the Monorail’s footprint) and even driving alone in a private car (0.52 lb/passenger-mile, per EPA) emits roughly 8 times more.

Please find the chart below that shows Monorail’s footprint against both reference points on the same scale.
